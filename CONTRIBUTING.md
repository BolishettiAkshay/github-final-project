# Contributing to Simple Interest Calculator

Thank you for your interest in contributing to the Simple Interest Calculator project.

All contributions are welcome. We appreciate contributions that help improve the project and make it more useful to the community.

## Ways to Contribute

The following types of contributions are welcome:

- Bug reports
- Bug fixes
- Documentation improvements
- Enhancements
- New ideas and suggestions

## Reporting Bugs

If you find a bug, please create an issue and provide a clear description of the problem, steps to reproduce it, and any relevant information.

## Suggesting Enhancements

If you have an idea or enhancement that could improve the project, please open an issue and describe your suggestion and its benefits.

## Documentation

Improvements to the documentation are also welcome. Please make sure that documentation changes are clear and easy to understand.

## Code Contributions

Before submitting code changes, make sure that your changes are tested and that they do not introduce unnecessary issues.

Thank you for helping improve this project!
